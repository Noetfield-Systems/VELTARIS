Issuance API

Preview proposed units and a transfer decision using sample terms. The endpoint evaluates a single scenario without holding state or signing a transaction.

Quickstart

Send a JSON object to POST /v1/issuance/simulate. Monetary inputs use integer CAD cents. The principal must divide evenly by unit price.

curl https://veltaris-capital.vercel.app/v1/issuance/simulate \
  -H 'content-type: application/json' \
  -d '{"principalCents":10000000,"unitPriceCents":10000,
       "holdingUnits":200,"requestedUnits":75,
       "senderVerified":true,"recipientVerified":true,"paused":false}'

Expect a proposed supply of 1,000 units, a simulated transfer of 75 units worth CAD 7,500, and 125 units remaining with the sender. A policy rejection returns HTTP 200 with allowed: false and reason codes. Invalid terms return HTTP 400.
